توزيع الأدوار والمسؤوليات

أوتوميشن مهندس الأوتوميشن

الأجهزة · الشبكة الصناعية · الميدان · التوصيلات
  • إعطاء IPs ثابتة لكل أجهزة Modbus وربطها على الـ Switch
  • ضبط محوّل RS485↔Ethernet للعدّادات التسلسلية
  • تهيئة وحدتَي IO Modbus 8-CH وخريطة الـ registers
  • توصيل حسّاسات الكراتين عبر ريليهات SSR على الـ DI
  • ضبط نسب الـ CTs في عدّادات الطاقة
  • رسم مخطط الشبكة والتوصيلات (Wiring Diagram)
  • نسخ احتياطية لإعدادات الأجهزة (IO / Weintek / العدّادات)
  • تجهيز عُدّة الموقع الميدانية

سوفتوير مهندس السوفتوير

المنصّة · الداتابيز · التكامل · الداشبورد
  • تجهيز الكمبيوتر الصناعي وتشغيل ستاك Docker كامل
  • ضبط ملفات .env والمنافذ والإقلاع التلقائي
  • تهيئة الداتابيز والبيانات الأساسية (ISA-95 + SKUs + Users)
  • تشغيل وتهيئة Edge Gateway وتعريف الـ Tags
  • تأكيد نشر توبيكات MQTT ومراقبة الـ broker
  • اختبار سلسلة العدّ وبثّ WebSocket للداشبورد
  • التحقق من حساب OEE / AT-OEE و store-and-forward
  • Backup الداتابيز و Docker images

مهام مشتركة (تنسيق الطرفين)

  • مطابقة كود الماكينة مع machineKey
  • جدول Register Map و I/O
  • تعريف الأجهزة والـ Tags في الـ Edge
  • اختبار التدفّق الكامل (E2E) و UAT
  • التشغيل التجريبي وقائمة Go/No-Go
  • التركيب والتشغيل في الموقع
