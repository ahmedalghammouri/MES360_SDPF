01 · Overview

ما هو MES360°؟

منصة تنفيذ تصنيع (Manufacturing Execution System) كاملة وفورية، تربط ما بين الأرضية الصناعية (Shop Floor) وأنظمة التخطيط والإدارة العليا في طبقة واحدة موحّدة.

تجمع MES360° المراقبة اللحظية للإنتاج، وإدارة الجودة، والصيانة التنبؤية، والربط عبر إنترنت الأشياء الصناعي، ورؤى الذكاء الاصطناعي — في منصة مؤسسية واحدة متعددة المصانع.

رؤية لحظية 360° متعدد المصانع عربي / إنجليزي (RTL) جاهز للسحابة والحافة
🏭

الأرضية الصناعية

ربط الآلات والحساسات وجمع البيانات لحظياً عبر MQTT و OPC-UA و Modbus.

📊

الذكاء التشغيلي

مراكز قيادة ولوحات معلومات و OEE وتحليلات تكشف الأداء فوراً.

✅

الجودة والامتثال

الفحوصات و SPC و NCR و CAPA مع سجل تدقيق كامل وتتبّع للمصدر.

🤖

الذكاء الاصطناعي

كشف الشذوذ والتنبؤ بالأعطال والمقارنات المرجعية بين الخطوط.

01 · The Problem

التحديات التي يعالجها النظام

المصانع التقليدية تعمل ببيانات متفرقة ومتأخرة، ما يخفي الخسائر الحقيقية.

🕳️

بيانات معزولة

أنظمة منفصلة (إنتاج، جودة، صيانة، مخزون) لا تتحدث مع بعضها، فتغيب الصورة الكاملة.

⏱️

قرارات متأخرة

تقارير يدوية تصل بعد فوات الأوان، فتُكتشف التوقفات والخسائر متأخرة.

📉

غياب قياس OEE

لا قياس موثوق للكفاءة الكلية للمعدات يكشف فجوات التوفر والأداء والجودة.

🔧

صيانة تفاعلية

إصلاح بعد العطل بدل التنبؤ به، ما يرفع التوقفات غير المخطّطة والتكاليف.

🔍

تتبّع ضعيف

صعوبة تتبّع الدفعات والمواد من المصدر إلى المنتج النهائي عند الحاجة.

📑

امتثال يدوي

سجلات ورقية يصعب تدقيقها وتعريضها لمخاطر الجودة والمطابقة.

01 · Objectives

أهداف MES360°

  • توحيد المصدر الواحد للحقيقة — دمج كل بيانات التصنيع في منصة واحدة متّسقة.
  • رفع الكفاءة الكلية للمعدات (OEE) — قياس التوفر والأداء والجودة لحظياً وكشف الخسائر.
  • خفض التوقفات غير المخطّطة — تحليل الأعطال والصيانة الوقائية والتنبؤية.
  • ضمان الجودة والامتثال — فحوصات و SPC و NCR/CAPA بسجل تدقيق كامل.
  • تتبّع كامل من المصدر للمنتج — شجرة أنساب الدفعات والمواد والاستهلاك.
  • تمكين القرار اللحظي — مراكز قيادة وتنبيهات فورية للإدارة والمشغّل.

04 · How it works

كيف يعمل النظام — تدفّق البيانات اللحظي

①
التقاط من المصدرالحساسات و PLC تُرسل البيانات عبر MQTT / OPC-UA / Modbus.
②
بوّابة الحافة (Edge Gateway)تجميع وتطبيع البيانات قرب المصدر قبل إرسالها.
③
التخزين والمعالجةInfluxDB للسلاسل الزمنية · PostgreSQL للبيانات التشغيلية.
④
البث اللحظيWebSocket (Socket.IO) يدفع التحديثات للوحات فوراً.
⑤
الرؤية والتنبيه والقرارمراكز قيادة · OEE · تنبيهات · رؤى ذكاء اصطناعي.
  • زمن استجابة منخفض — من الحساس إلى الشاشة في ثوانٍ عبر البث المباشر.
  • بيانات موثوقة — تطبيع وتحقق عند الحافة وقبل التخزين.
  • شارات لحظية — عدّادات مباشرة لعناصر العمل المعلّقة والتنبيهات في القائمة.
  • سجل تاريخي كامل — كل قياس محفوظ لإعادة التحليل والمقارنة.
  • قابلية التوسّع — معمارية حاويات تتوسّع مع نمو عدد الأجهزة والمصانع.
04 · OEE Methodology

منهجية حساب الكفاءة الكلية

OEE = Availability × Performance × Quality
⏱️

التوفّر · Availability

Run Time / Planned Time

يقيس الخسائر الناتجة عن التوقفات المخطّطة وغير المخطّطة.

⚡

الأداء · Performance

(Ideal Cycle × Count) / Run Time

يقيس خسائر السرعة والتوقفات الصغيرة عن المعدّل المثالي.

✓

الجودة · Quality

Good Count / Total Count

يقيس خسائر العيوب وإعادة العمل من إجمالي الإنتاج.

يُحسب الـ OEE لحظياً على مستوى الآلة والخط، مع تتبّع الست خسائر الكبرى (Six Big Losses) لكشف فرص التحسين الدقيقة.

05 · Security

الأمان والصلاحيات

  • مصادقة JWT عبر Passport.js مع استراتيجيات محلية وآمنة.
  • تحكّم بالوصول حسب الدور (RBAC) — صلاحيات دقيقة من SUPER_ADMIN حتى المشغّل.
  • عزل متعدد المصانع — كل مستخدم يرى بيانات منشآته المصرّح بها فقط.
  • رؤوس حماية HTTP عبر Helmet والتحقق من المدخلات بـ Class-Validator / Zod.
  • تحديد معدّل الطلبات على مستوى الـ Nginx لصدّ الإساءة.
  • سجل تدقيق كامل لكل العمليات الحسّاسة في الجودة والمخزون والإنتاج.
