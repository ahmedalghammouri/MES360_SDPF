## ⚠️ Security note

- These are **default seed credentials**, documented in the seed source and printed to the API boot log — treat them as **public knowledge** until changed.
- The super-admin pattern (`<email>@<email>`) is guessable. **Change all three super-admin passwords immediately.**
- Accounts created later via the User Management UI are **not** in this list, and any account whose password was changed will **not** match here.
- Passwords are stored as bcrypt hashes and **cannot be recovered** — this file reflects the seed defaults only.
- To list the **real** current accounts on the live server:
  ```bash
  docker exec mes-postgres-prod psql -U mes_user -d mes360 -c \
    "SELECT email, name, role, \"isActive\", \"lastLoginAt\" FROM users ORDER BY role, email;"
  ```
